Getting Started

Welcome to the RinoxAuth API. This portal provides comprehensive technical documentation for integrating our high-security authentication platform into your enterprise application. Follow this guide to issue your first authenticated request.

Base API URL content_copy
https://api.rinoxauth.v1.enterprise.cloud

Quick cURL Request

Use this snippet to verify your integration and connectivity.

curl -X GET "https://api.rinoxauth.v1.enterprise.cloud/v1/health" \
  -H "Authorization: Bearer $RIN_API_KEY" \
  -H "Accept: application/json"

Authentication

RinoxAuth uses industrial-grade security protocols. Every request to our API must be authenticated using either a Standard API Key or a JWT (JSON Web Token) generated via the OAuth2 flow.

key

API Key Authentication

Recommended for server-side integration and automated background tasks. Use the X-API-KEY header.

badge

JWT Authentication

Ideal for frontend applications. Tokens are valid for 1 hour and must be refreshed using the refresh_token flow.
